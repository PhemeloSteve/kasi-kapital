# Runbooks

Short, step-by-step pages for when something goes wrong. Keep them in the repository so they are
there when the site is not. **A draft:** have your Information Officer or a lawyer read the data breach part
before launch.

| Situation                              | Runbook                                      |
| -------------------------------------- | -------------------------------------------- |
| Anything serious, start here           | [incident-response.md](incident-response.md) |
| Someone else may be using an account   | [account-takeover.md](account-takeover.md)   |
| A key or password has leaked           | [secret-rotation.md](secret-rotation.md)     |
| Supabase, Vercel or Cloudflare is down | [outage.md](outage.md)                       |
| Backups and getting data back          | [backups.md](backups.md)                     |
